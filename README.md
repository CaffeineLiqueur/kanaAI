# kanaAI - AI日语学习应用

宝可梦风格的日语学习Web应用，集成AI辅助学习功能，包含像素风宠物互动系统。

## ✨ 功能特点

### 📚 学习模块
- **假名学习** - 平假名/片假名图鉴式收集
- **词汇记忆** - 艾宾浩斯遗忘曲线复习
- **语法入门** - AI生成易懂解释
- **AI对话** - 场景化日语对话练习
- **智能测验** - AI根据进度动态出题

### 🐾 宠物系统
- 领养柴犬/猫咪/兔子
- 学习获得经验值，宠物升级
- 3阶段进化系统（幼年→成长→成年）
- 喂食、装扮、互动功能

## 🛠️ 技术栈

| 模块 | 技术 |
|------|------|
| 前端 | React 19 + TypeScript + Next.js 16 |
| 样式 | Tailwind CSS 4 + 像素风主题 |
| 状态管理 | Zustand |
| 数据库 | PostgreSQL + Prisma |
| AI | Vercel AI SDK (Anthropic/OpenAI) |
| 动画 | Framer Motion |

## 🚀 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`，填入你的API密钥：

```bash
cp .env.example .env
```

### 3. 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:3000

## 🎮 使用说明

### 假名学习
- 选择平假名或片假名
- 点击假名查看详情
- 完成小测验获得经验值

### 词汇学习
- 按分类浏览词汇
- 翻转卡片学习单词
- 标记掌握程度

### AI对话练习
- 选择场景（自我介绍、餐厅、购物等）
- 与AI进行日语对话
- 获得实时纠错和建议

### 宠物系统
- 学习获得经验值
- 喂食、摸摸宠物
- 宠物会升级进化
